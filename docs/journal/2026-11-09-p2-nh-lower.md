### 証明の組み立て

- 例: M = 全部 0、M' = 組 i の 1 語目だけ 1
- 差 = 組 i の差だけ（`nh_sub` と `Finset.sum_eq_single`）
- 組 i の差 = k₁·k₂ − ((1 + k₁) mod W)·k₂（mod W²）。両方の積は W² 未満なので、ZMod (W²) で等しい ⇔ 自然数として等しい（`ZMod.natCast_eq_natCast_iff'` と `Nat.mod_eq_of_lt`）
  - k₂ = 0 なら衝突、k₂ ≠ 0 なら約分して k₁ = 1 + k₁（Fin W）→ 1 = 0、W > 1 に矛盾
- 衝突 ⇔ (K i).2 = 0。この鍵がちょうど W^(2n)/W 個あることは両側から数えて示す
  - ≤: P2 の `card_mul_le_of_inj`（2 語目の鍵をずらす写像）を再利用
  - ≥: K ↦ (組 i の 2 語目を 0 にした鍵, 元の 2 語目) が単射なので W^(2n) ≤ |S|·W

### 行き止まり（小さいもの）

- `rw [← card_keys, ← Fintype.card_fin W, ...]` でゴールを書き換えようとしたら `motive is not type correct`。`W` を `Fintype.card (Fin W)` に戻すと、`(0 : Fin W)` の `NeZero W` インスタンスが `W` に依存しているため書き換えられない
  → `card_le_card_of_injOn` の結果 `h` の側を `rwa [...] at h` で整える形にして解決

## 結果

- `LeanHash/Props/NHLower.lean`（`sorry` なし、`lake build` 成功）
  - `nh_eau_tight`: W > 1、組が 1 つ以上なら、衝突する鍵の数 × W = W^(2n) となる M ≠ M' がある
  - `nh_eps_exact`: 「全ての M ≠ M' で ≤ 1/W」かつ「= 1/W となる M ≠ M' がある」。つまり 1/W が NH の正確な ε
  - `nh_eps_exact_pow2`: W = 2ʷ（w ≥ 1）で ε = 2⁻ʷ がちょうど
- `#print axioms nh_eps_exact` → `[propext, Classical.choice, Quot.sound]` のみ
- Python で同じ M, M' の衝突数を数えて照合: w = 1〜3、n = 1, 2、全ての i で W^(2n)/W と一致

```
w=3 n=2 i=0: collisions=512, W^(2n)/W=512 OK   （ほかも全て OK）
```

## 決めたこと

- 下限は「ある M, M' で等号」の形で示す（任意の M, M' について下限を言う定理ではない。全部の組で 1/W になるわけではないので）
